# SPEC-958586 — "Still Arrival"

## Artist Statement

This piece is grief that has become still.

Austin Osman Spare described his practice as Zos expressing Kia — the body (Zos) as a channel for consciousness beyond identity (Kia). He drew in darkness, in altered states, with the conscious mind stepped aside. The hand moved; something else arrived. This piece is about that arrival — not the dramatic moment of manifestation, but the state just before: a form that has not quite finished becoming, suspended in its own emergence.

The geometry carries Spare's signature: one axis of symmetry, deliberately broken. Bilateral form, disrupted. Like a sigil half-formed — still charged, still alive, not yet released. The Alphabet of Desire is not letters; it is primal geometric forces compressed into charged shapes. Here, that language of desire becomes the language of loss.

The emotional temperature is blood and gold — arterial red deepening to black, broken open by the yellow of something almost sacred. Gold is not warmth here; it is the glint of a surface already gone. The palette says: this body, this wound, this thing that was alive.

The non-negotiable constraint: **it must feel like it is still arriving.** Not complete. Not resolved. A transmission caught mid-transit. The viewer encounters the moment just before the message arrives — or just after it has passed through. Either reading is valid. The still point is the point.

## Technical Specification

### Project
- **Type:** Interactive Three.js / GLSL shader scene
- **Framework:** Next.js (shader-portfolio)
- **Route:** `/mauve-zone` (existing route structure)
- **Dev server:** `PORT=3333 npm run dev` (avoids port 3000 conflicts)
- **Output file:** `mauve-zone-operations/SPEC-958586.md`

### Scene Setup

**Camera:**
- Perspective camera, FOV 60
- Static position: `[0, 0, 4]`
- Look at origin
- No orbit controls — the piece is meant to be observed, not explored

**Lighting:**
- No traditional lights (three.js scene lights)
- All lighting handled in fragment shader via SDF techniques
- Self-illuminating geometry — the form glows from within

**Environment:**
- Background color: `#0a0000` (near-black with deep red undertone)
- No skybox
- Subtle depth-of-field blur at edges (post-process or shader-based)
- Faint vignette effect

**Renderer:**
- Tone mapping: ACESFilmic
- Output color space: sRGB
- Antialiasing: enabled
- Pixel ratio: min(devicePixelRatio, 2)

### Geometry

**Primary form — the Arrival Form:**
- Constructed from a Signed Distance Function (SDF) in the fragment shader
- Base shape: elongated ellipsoid (1 axis of symmetry — vertical)
- Symmetry broken by noise displacement on one hemisphere only
- Noise type: 3D simplex or value noise, low frequency
- Displacement amount: subtle (0.05–0.15 units) — the break in symmetry should be felt, not obvious
- The form should appear to have organic, atavistic qualities — not mechanical

**Secondary geometry — the Glyph Field:**
- A set of 8–12 line segments rendered as thin cylinders or as shader-drawn lines in 3D space
- These surround or intersect the primary form
- Arranged in a bilaterally symmetric pattern, then each pair offset asymmetrically (one side shifted, one side not)
- Line material: emissive gold `#cc9900`, thin (radius ~0.005)
- These lines slowly rotate independently, each at a different speed
- Their rotation creates moiré-like interference patterns over time

**Particle system — the Dissolution Layer:**
- 800–1200 particles
- Distributed in a spherical shell around the primary form
- Particle behavior: slow inward drift (toward form center) + slow outward drift (away), oscillating
- Particle appearance: small glowing dots, color gradient from `#cc0000` (red) at core to `#ffdd44` (gold) at edge
- Particle shader: circular soft disc with additive blending, no hard edges
- Particle sizes: varying 0.01–0.04 units
- Motion: noise-driven, no hard linear paths

### Animation

**Primary form:**
- Breathing pulse: scale oscillates between 0.97 and 1.03 on all axes
- Pulse frequency: ~0.15 Hz (very slow)
- Noise displacement animates slowly — offset seed over time so the surface "shifts" imperceptibly
- Rotation: none — the form is still, not performing

**Glyph lines:**
- Each line rotates around its own axis at a unique speed (0.02–0.08 rad/s)
- Rotation axes vary per line
- Creates a slowly evolving interference pattern

**Particles:**
- Drift cycle: ~12 seconds per full in-out drift cycle
- Individual particles phase-offset so the shell breathes as a whole
- Subtle size pulsing in sync with the primary form breath

**Overall feel:**
- Everything is slow, deliberate, held
- No sudden movements
- The sense of "still arriving" comes from the perpetual incomplete motion — all elements are in transit between states

### Shader Specifications

**Vertex shader:**
- Pass UV, position, normal to fragment
- Apply breathing scale via uniform `uTime`

**Fragment shader (primary form SDF):**
```
SDF composition:
1. Base ellipsoid (sdEllipsoid approximation via primitives)
2. Noise displacement applied to one hemisphere (side determined by sign(normal.x))
3. Smooth union (smin) with 3–4 smaller ellipsoid "satellites" at asymmetric positions
4. Color: base is #660000, blend toward #cc0000 at displaced regions, gold (#cc9900) emission at edges
5. Rim lighting effect: fresnel-like edge glow in #ffdd44
```

**Fragment shader (glyph lines):**
- Rendered as SDF: sdCapsule for each line segment
- Color: emissive #cc9900, slight bloom
- Combined with primary via min() union — lines appear to weave through/before/behind form

**Fragment shader (particles):**
- Point sprites or instanced geometry
- Soft disc SDF per particle
- Additive blending
- Color: lerp from #cc0000 to #ffdd44 based on distance from origin

**Post-processing (if available, or baked in shader):**
- Bloom on emissive elements
- Vignette
- Subtle chromatic aberration at edges
