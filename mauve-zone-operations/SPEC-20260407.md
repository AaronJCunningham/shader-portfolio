## Artist Statement (50%)

A hermetic glyph does not sit still. It *breathes*.

Steffi Grant's glyphs were transmission devices — not decorative but functional. They operated from inside Kenneth Grant's Mauve Zone: that liminal space between waking and void, between form and dissolution, where genuine magical and creative transmission occurs.

**The Nightside Breathes** is the visualization of that transmission happening *in real time*. 

Imagine a grid — the structure of the manifested world, the Tree of Life mapped into three dimensions, the architecture of consciousness itself. Now imagine that grid breathing. Expanding outward from a still center, then collapsing inward, as if the center is a heart, as if form itself is alive.

The colors move from blood (the material world, embodied, present) through gold (the solar, the transcendent, the unified) — a slow alchemical transformation happening within a single breath cycle. The motion is involuntary: not walking toward something, but breathing. Organic. Unavoidable. The fundamental rhythm of existence itself.

At the center, the grid buckles. The structure destabilizes. Something is trying to come through — or trying to escape. The nightside is never still. The mauve zone is never empty. There is always transmission happening, always something being born or dying at the threshold.

This is a portrait of a moment when the grid realized it was alive.

## Technical Specification (50%)

### Core Concept
A 3D volumetric grid that breathes rhythmically, with distortion concentrated at the center. The grid should feel alive, organic, with smooth sine-driven breathing motion rather than mechanical animation.

### Canvas & Camera Setup
- Full viewport 3D scene with React Three Fiber
- Camera: `position: [0, 0, 8]`, `fov: 50`
- Background: `#1a0000` (deepest blood)
- No post-processing; all effects in shader

### Geometry & Structure
**Single Primitive Approach:** Use a single `BufferGeometry` with:
- Grid vertices: 21×21×21 lattice (441 points per layer, 3 layers)
- Each vertex position stores its original position in an attribute for spring-back behavior
- Edges drawn via `LineSegments` with same vertices

**Vertex Layout:**
- Center at origin
- Extends ±2.0 on X, Y, Z
- Vertices indexed to compute their distance from center

### Shaders

#### Vertex Shader
```glsl
uniform float uTime;
uniform float uBreathIntensity;

attribute vec3 aOriginalPos;

varying float vDistance; // distance from center
varying float vBreathe;

void main() {
  vec3 pos = aOriginalPos;
  
  // Distance from center (0,0,0)
  float dist = length(pos);
  vDistance = dist;
  
  // Breathing cycle: smooth sine wave, 6-second period
  // Intensity peaks then falls back to 0
  float breathCycle = sin(uTime * 1.047) * 0.5 + 0.5; // 0..1
  vBreathe = breathCycle;
  
  // Center buckles inward most, outer grid holds relatively steady
  // Falloff: strong near center, zero at edges
  float centerMask = exp(-dist * dist * 2.5); // Gaussian falloff
  
  // Inward buckle when breathing (cycles through expand/contract)
  float buckleFactor = mix(1.0, -0.5, breathCycle); // 1.0 (normal) → -0.5 (inward)
  
  // Apply displacement: radial breathing at center
  pos += normalize(pos) * dist * buckleFactor * centerMask * uBreathIntensity;
  
  gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
}
```

#### Fragment Shader
```glsl
varying float vDistance;
varying float vBreathe;

void main() {
  // Palette: blood → gold
  // #1a0000 (deep blood) → #660000 → #cc0000 → #cc9900 → #ffdd44 (gold)
  
  vec3 blood = vec3(0.102, 0.0, 0.0);      // #1a0000
  vec3 darkRed = vec3(0.4, 0.0, 0.0);      // #660000
  vec3 red = vec3(0.8, 0.0, 0.0);          // #cc0000
  vec3 orange = vec3(0.8, 0.6, 0.0);       // #cc9900
  vec3 gold = vec3(1.0, 0.867, 0.267);     // #ffdd44
  
  // Color interpolation based on distance from center + breathing
  float t = (vDistance / 2.8) * (1.0 + vBreathe * 0.4);
  t = clamp(t, 0.0, 1.0);
  
  vec3 col;
  if (t < 0.25) {
    col = mix(blood, darkRed, t * 4.0);
  } else if (t < 0.5) {
    col = mix(darkRed, red, (t - 0.25) * 4.0);
  } else if (t < 0.75) {
    col = mix(red, orange, (t - 0.5) * 4.0);
  } else {
    col = mix(orange, gold, (t - 0.75) * 4.0);
  }
  
  // Breathing makes colors pulse slightly brighter at peak
  col *= mix(0.8, 1.2, vBreathe);
  
  gl_FragColor = vec4(col, 0.9);
}
```

### Animation
- **Breathing Cycle:** 6 seconds (sin wave, continuous loop)
- **Intensity Parameter:** `uBreathIntensity` = 0.6 (adjustable for intensity)
- **No easing:** Raw sine for organic, involuntary feel

## Visual Goals

- **Stillness at center:** The breathing is involuntary, not frantic
- **Structure intact:** The grid holds its form; it buckles but doesn't break
- **Color transmutation:** Blood → Gold over time, visible as layers expand
- **Hypnotic quality:** Viewers should feel the rhythm, want to watch the next breath
- **Precision + mystery:** Exact grid geometry, but the breathing makes it strange

The constraint is satisfied: motion is like breathing, not walking. No decision, no intent — just the fundamental pulse of existence.
