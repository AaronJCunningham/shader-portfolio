# What is Generative Art?
*Source: [Avant Art](https://avantarte.com/insights/guides/what-is-generative-art) — accessed 2026-04-04*

## TL;DR
Generative art = art made with an autonomous system (algorithm, random process) that determines final characteristics without direct human input on each output. Not AI art. Not NFT-specific. Not new — Mozart was doing dice-roll composition in the 1700s.

## Key Points

**Definition**
An autonomous system — algorithm, dice, code — makes decisions that determine the artwork's final form. The human sets up the system, the system runs it. The artist is a designer of processes, not a brush.

**Historical Lineage**
- Mozart: Musikalisches Würfelspiel — dice-determined music composition (18th century)
- Max Bense (1950s): "generative aesthetics" — theory of artificial production of innovation probabilities
- Sol LeWitt: instructions-based systems art, predetermined rules executed across media
- Bridget Riley: Op Art logic-driven geometry
- Bell Labs / IBM / NASA: early computer art
- 1968: ICA London — Cybernetic Serendipity exhibition (first major institutional computer art show)
- 2000s: Processing, Processing.js, Flash — democratized creative coding

**The Capital G Distinction**
"Generative Art" (blockchain-specific) = art minted on-chain via smart contracts, typically on Art Blocks. "generative art" (lowercase) = the broader practice.

**Generative ≠ AI**
Tyler Hobbs: "at the core is creative coding — writing programs that generate artwork." The artist codes the system, runs it many times, selects favorites. Smart contracts can generate unique works unseen by artist and collector — no AI required. Art Blocks works work this way: collector triggers the algorithm, new work is minted.

**Tyler Hobbs / Fidenza**
Carefully programmed randomness. Runs 100-200 outputs, selects favorites. Sometimes plotted to paper. Fidenza is his "most versatile algorithm to date."

**Dmitri Cherniak / Ringers**
Code visualizes strings wrapped around pegs. #879 ("The Goose") sold for $6.2M at Sotheby's. The algorithm: peg grid → sampling → center of gravity calc → sorting → angles/arcs/tangents. Mathematical constraints enforce artistic objectives. The viral meme recognition was accidental.
